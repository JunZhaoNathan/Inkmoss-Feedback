# Inkmoss Bug Feedback

Inkmoss 官方公开 bug 反馈通道。

[反馈bug](https://github.com/JunZhaoNathan/Inkmoss-Feedback/issues/new?template=bug-report.yml) · [查看处理进度](https://github.com/JunZhaoNathan/Inkmoss-Feedback/issues)

使用 GitHub 账号提交文字和图片。反馈默认分配给维护者；后续复现、修复与发布状态
记录在同一条 issue 中。状态标签为 `status:triage`、`status:confirmed`、
`status:in-progress` 和 `status:fixed`；关闭时说明处理结果。

所有 issue、评论和附件公开。提交前移除私人文稿、个人资料、路径和凭据；仅附上
可以公开的最小示例。本仓库不接收软件自动诊断批次，不含 Inkmoss 私有源码。

## English

The official public bug tracker for Inkmoss.

[Report a bug](https://github.com/JunZhaoNathan/Inkmoss-Feedback/issues/new?template=bug-report.yml) · [Track bugs](https://github.com/JunZhaoNathan/Inkmoss-Feedback/issues)

A GitHub account is required to submit text and images. Reports are assigned to the
maintainer. Reproduction, fixes and release status stay in the same issue. Status
labels are `status:triage`, `status:confirmed`, `status:in-progress` and `status:fixed`;
the resolution is explained when an issue is closed.

Issues, comments and attachments are public. Remove private writing, personal
information, paths and credentials before submitting. Include only a minimal example
you can share publicly. This repository does not receive automatic diagnostic batches
and does not contain Inkmoss's private source code.
